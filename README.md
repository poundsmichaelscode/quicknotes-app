# QuickNotes

QuickNotes is a simple browser-based note-taking application built with HTML, CSS and JavaScript. It allows users to create notes, organise them into Personal, Work and Study categories, search through existing notes, delete notes and keep their data saved between browser refreshes using localStorage.

## Features

- Add new notes
- Personal, Work and Study categories
- Category-specific note card colours
- Delete individual notes
- Search notes in real time
- Case-insensitive searching
- Note validation
- Maximum note length of 200 characters
- Automatic note count
- LocalStorage data persistence
- Responsive design for desktop and mobile
- Clear all notes with confirmation
- Creation date and time displayed for every note
